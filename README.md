# Scraping Analyst Portfolio

Belajar web scraping untuk Data Analyst.

## Setup
1. `python -m venv venv`
2. `venv\Scripts\activate`
3. `pip install -r requirements.txt`

## Struktur
- `src/` — kode scraper
- `data/raw/` — data mentah
- `data/processed/` — data bersih
- `data/output/` — hasil akhir
- `notebooks/` — analisis Jupyter
